- **T003/T004 (header skeleton + pole tables)**: `if (poleTablesDirty_) rebuildPoleTables();` deliberately deferred to T004 rather than added in T003, per the task split; `resolveTiltScratch()` deferred likewise. `rebuildPoleTables()` clears `poleTablesDirty_` at the top rather than at the end (functionally equivalent, strictly safer on the unprepared early-return path) — left as-is to avoid churning a working line. OverlapAdd's kaiserBeta passed as the named `kDefaultKaiserBeta` constant rather than the literal `9.0f` the plan spells (same value).
- **T006 (chunk pump loop)**: `smearMagnitudes`/`decohere` landed as identity stubs with `[[maybe_unused]]` params in this task, filled by T007/T009 respectively — matches the task's own sequencing.
- **T007 (magnitude memory)**: `handlePoison` stubbed as `return true;` pending T011, per the plan; test controls set *before* `prepare()` so the frame-clock smoother snaps to exact endpoints on frame 0, making the priming-vs-zero-init discrimination exact rather than approximate (documented rationale: a zero-init memory would still fail the gate, just with a smaller margin).
- **T008 (magnitude-law spectral tests)**: two measurement decisions flagged as open risk, not threshold changes — (1) the gated-tone probes for SC-004(c)/SC-010 ride a constant ~-70 dBFS noise floor rather than digital silence, because true silence collapses every analysed phase to exactly 0 and biases the decay-time measurement independent of tau; (2) the 4 Hz AM depth is full-depth to maximise removable flux. Both are documented in-file for the next reader. All measured numbers subsequently landed inside gate on the final run (see FR-030/032, SC-004).
- **T009 (decoherence + click/pre-echo arm c)**: added an anti-vacuity comparison (a park-length pair that must *fail* `compareFingerprints`) beyond the letter of the task, so SC-009(c)'s pass could not be vacuous.
- **T011 (poison handling + non-finite TU)**: `handlePoison` implemented with an explicit no-latch deviation from `AtmosphereEngine`'s (:2244-2260) latched-poison behavior — re-arms priming and clears both magnitude and phase for every bin, then returns, allowing self-recovery on the next clean frame. Documented rationale: a global stereo bus should not permanently mute on one bad sample.
- **T012 (30-minute soak)**: gap regions use true digital silence (per the criterion's own wording), which is documented as producing a *faster*-than-exponential tail via the zero-phase/Hann-synthesis-edge mechanism; the monotonicity arm (not the raw -40 dB crossing) is the one asserted across the full gap remainder for that reason. No noise floor was added to the gaps, and no threshold was loosened.
- **T013 (CPU budget)**: first authored with **provisional, unmeasured baseline projections** and an explicit flag that configuration (d) — synchronous per-block pole-table rebuild at fft 4096 — was arithmetically predicted to blow the ceiling by 6-8×. This was **not** a false alarm: a subsequent full build run (recorded under CC-warnings) confirmed 4 real failures, including the perf regression at (d). The fix (outside T001-T016's scope as originally written, applied before this compliance pass) replaced the per-bin scalar transcendental loop in `rebuildPoleTables()` with 7 bulk SIMD passes via `core/spectral_smear_simd`'s `batchLog10`/`batchPow10`, bringing (d) from ~217-236 µs/block down to 33.078 µs/block — inside the 35.556 µs ceiling. The baseline provenance banner was also completed (five P-core-pinned idle runs, worst-of-five, documented spreads).

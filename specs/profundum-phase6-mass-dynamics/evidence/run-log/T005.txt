== Decisions ==
- D-1 DTr fixture placement: the task fixes x (E1 sine 1.5 s), the boost (100 ms) and W (375 ms) but not onset / steadyStart.
  Chosen onset = 0, steadyStart = 1.0 s (48000; 48000 + 18000 <= 72000). Sizing check in a scratch Node model
  (float32 sine, same arithmetic): onset 0 / steady 1.0 s -> 2.5308 dB vs 2.5527 expected (|err| 0.022 < 0.05); other
  placements checked: (0, 1.125 s) 2.5297, (2400, 1.0 s) 2.5646, (0, 0.75 s) 2.5219, (1200, 50000) 2.5349 — all inside the bar.
  The residual is the non-integer-period energy of the 100 ms / 375 ms windows, not a helper error. No bar relaxed.
- D-2 Infinity: transientTimeMs returns ProfundumTest::posInf() (bit pattern through a volatile sink), never
  std::numeric_limits<double>::infinity(): the TU is compiled under -ffast-math on clang (-Wnan-infinity-disabled would break
  the zero-warning rule), per the precedent in spectral_shape_recipe_test_helpers.h:12-18.
- D-3 Extra helpers beyond the task's list (all used by the self-test or by burst/twoLevelStep): kRampMs, secondsToSamples,
  rampSamples(fs) (= round(0.5 ms * fs)), rampWeight(k, R) (= 0.5*(1 - cos(pi*k/R))). The ramp is 0 at k = 0 and < 1 at
  k = R - 1; full gain from k = R. The self-test checks rampSamples(48000) == 24, b[onset+k] == tone[k]*w(k) within 1e-7 for
  k < 24, |b[onset+23]| < |tone[23]|, and b[onset+k] == tone[k] exactly for k >= 24 (same build, same process: rule 7).
- D-4 Signatures: gain traces are std::span<const float> (transientTimeMs, rippleDb, meanOf); audio is const float* + n
  (dTrDb, levelDbPeriods, sideMidRatioDb). levelDbPeriods measures from y[0] over integerPeriodLength(n, fs, f0, 0.0)
  samples (callers pass y + start). transientTimeMs searches the peak over [onset, onset + round(searchMs*fs/1000)]
  inclusive and the -3 dB crossing to the end of the trace.
- D-5 twoLevelStep renders the tone once for low + high seconds (one continuous waveform) and applies the gain
  envelope; total = round(low*fs) + round(high*fs).
- D-6 The T002 stub's #include <krate/dsp/processors/transient_shaper.h> was replaced by the helper header (the
  self-tests do not use TransientShaper).

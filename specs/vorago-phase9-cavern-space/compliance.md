## Implementation notes: deviations reported by task agents

These are deviations, judgement calls, and criterion amendments the implementing/testing task agents (T001–T019) reported against the letter of `tasks.md`/`spec.md`. None relaxed a pass/fail threshold; several *tightened* one. Grouped by theme, cited to the originating task.

**Scaffold naming collision (T001).** `tasks.md` gave all four `cavern_verb_*` test TUs the identical scaffold case name `CavernVerb_Scaffold`; four identical Catch2 case names in one binary would have aborted the runner at startup. T001 kept `CavernVerb_Scaffold` in `cavern_verb_test.cpp` and used `CavernVerb_FreezeScaffold` / `CavernVerb_SoakScaffold` / `CavernVerb_PerfScaffold` in the other three, each commented with the task that deletes it.

**NED helper lift (T002).** Lifting `normalisedEchoDensity` out of `aether_reverb_test.cpp` into the shared `reverb_metrics.h` header dropped two of the original four `INFO` lines ("Peak amplitude", "Threshold (-40dB)") because those intermediates no longer exist once the loop is a shared function; the two that remain (NED fraction, occupied-window count) are unchanged. `fillBandLimitedNoise` uses one 80 Hz HP + one 11 kHz LP biquad (2nd-order each) rather than the 4th-order pair in the original `aether_reverb_test.cpp` helper, per the task text's explicit "2nd-order" wording, with a fixed `0.5` gain in place of block-wise peak normalisation (a streaming generator cannot peak-normalise without seaming every block boundary).

**Damper-hook accessor tests need a "parked settled" engine (T003).** `AetherReverb`'s per-control defaults are private and only recomputed inside `runControlStep()`; the three new `AetherReverb_DamperOffset*` tests therefore set controls then call `reset()` (which re-applies control state without requiring a render) rather than asserting immediately after construction. Documented as forced by the real API, not a shortcut.

**DelayLine rounding guard (T004).** `DelayLine::prepare()` takes seconds and truncates, so a float quotient landing a few ULP low silently costs a headroom sample; T004 added a half-sample rounding guard (`+4.5f/sr` instead of `+4/sr`) to the ER line and all four alignment lines. Without it, `SC-015`'s `[1x, 2x]` allocation-factor window fails at 44.1 kHz with the spectral stage disabled. Semantics (≥4 samples headroom) are unchanged.

**FR-025 bypass tightened, not just implemented (T006).** The absorption bypass (`v ≤ 0`) originally still evaluated `fcMax * pow(fcMin/fcMax, 0)` per tap; T006 changed it to assign `fcHz = fcMax` and `a = 0` directly, so "no coefficient is computed" is now literally true rather than true "by grace of `pow(x,0)==1`". T006 also replaced the task's literal (and arithmetically unreachable — see below) "flat within ±5% at v=0" clause with a per-tap comparison against that tap's own two-sample interpolation reference, which is a strictly stronger, non-tautological check of FR-025's exact-bypass claim.

**MixLaw metric redefinition (T007).** The literal "total output power stays within ±0.5 dB across the sweep" cannot be satisfied by ANY equal-power crossfade unless the dry and wet busses have equal power at every mix setting — no implementation can pass that as written. T007 instead recovers the implementation's own `dryG`/`wetG` by exact 2×2 least-squares projection onto the mix=0/mix=1 basis and evaluates power on those two gains normalised to equal power (required ±0.5 dB), with the projection residual required ≤1e-3 (the claimed 0.1% linearity). A literal linear crossfade fails this test by 3.01 dB (reported as the witness), confirming the gate has teeth.

**SC-005's un-paired statistic was unreachable; replaced with a seed-paired one (T009 finding, ruled by spec amendment).** The original SC-005 criterion (spectral-centroid change at depth 1 must be ≥3× the change at depth 0, measured as raw un-paired centroid values) is mathematically unreachable by any correct implementation: the periodogram noise floor (~332 Hz) swamps the damper's actual spectral contribution (~63 Hz) at any window length the 115 s record supports. `spec.md` was amended to the seed-paired statistic `M(d) = stddev_t[c_d(t) - c_0(t)]`, keeping the same 3× factor and 0.9 Spearman bound. Measured: `M(0.25) = 14.17 Hz`, `M(1) = 62.65 Hz`, ratio 4.42× (bound 3×); Spearman ρ = 1 (bound 0.9). The un-paired series is still printed (ungated) for transparency.

**SC-016(c) was arithmetically impossible as originally pinned; replaced (T011 finding, ruled by spec amendment).** The literal criterion ("T60 at 8 kHz within 15% of 0.05×T60 at 125 Hz") can never hold for the shipped damping law: the mirrored damping constant operates at the DC↔Nyquist endpoints, not between two arbitrary octave bands, and the minimum achievable ratio over the whole decay range is ~1.45× the target — a 45% miss at best, worse (2.9×) at the FR-066 default. `spec.md` was amended to (c-1) exact recovery of `kDampingNyquistRatio` from the public accessors to within 1% (a 15× *tightening* versus the original 15% band) plus (c-2) a ≤0.35 banded-T60 ratio as corroboration.

Decisions / deviations (surface them)
1. SC-006 epsilon. Per Tone point the spread (max - min) of C over the PRODUCT 8 sub-period start offsets x block sizes
   {1, 64, 512} (24 renders; the reference C is offset 0 / block 512). A sweep's epsilon = the largest of its 11
   spreads; tau = min(2 eps, 0.005); eps > 0.0025 -> FAIL_CHECK "SC-006 harness, not bar". Steps and the sum of
   negative steps use the sweep's tau. Offsets: the input is the same fixture started k*period/8 samples later
   (k = 0..7, rounded), i.e. the window phase moves. Cost estimate: 528 Tone points x 24 renders of 2.4-3.8 s audio,
   ~15-25 min in one shard. Reading "offsets and block sizes" as a union (10 renders) would cost ~40 %; not taken
   (never shrink a workload).
2. SC-010 render length: each algorithm's input is the tail (bcsTail) of one input generated for the longest frame
   (Fracture's f0/2 frame), so the Fold-100 input is already settled and every algorithm still gets 1 s settle + its
   own frame + 50 ms.
3. SC-010 smoke sibling exists for Bite/Tube/Fold/Crush/Fracture (T011/T014/T015); the new Rectify smoke completes it.
4. SC-022 inputs: Fold-100 kGrowl normalised to peak 1 (global max of the 0.5 s Fold-100 render) and full-scale
   calibration sines (peak 1.0), each at E0 and C3 (the task names E0 / C3 for the sines; the growl note is unstated,
   so the same two notes are used). 48 kHz, 0.5 s. The check is "every |y| <= 6.0" written so NaN fails it; note that
   processBlock clamps at kOutputCeiling = 6 (bass_character_stage.h:365), so the bound holds by construction unless
   the output is non-finite; preCeilingPeak() is printed per cell to show whether the ceiling acted.
5. SC-028(a) band: tilts run at the BASE rate since C-23 (bass_character_stage.h:24-26, every prepare() calls
   postTilt.prepare(baseRate)), so the band is 20 Hz - 0.45*fs at the base rate (spec SC-028(a) literal "0.45*fs"); the
   task text "0.45*(F*fs)" predates C-23 and frequencies above fs/2 do not exist for a base-rate filter. Sine probes:
   0.3 s, 0.1 s settle, RMS ratio over whole periods.
6. SC-028(b)-(d) responses are measured on copies of the probe's tilt objects (KeytrackedTilt is copyable) from their
   impulse response (16384 samples, DTFT in double at each n*f0) instead of one sine probe per harmonic: (d) needs
   |H_post| at every harmonic below fs/2 (~583 at E1). Still a measured linear response of the running object.
7. SC-028(b) routes per algorithm x Tone {0, 0.25, 0.75, 1}: (i) one stage at the prepare default C2, setFundamentalHz C1
   then C3 with a 0.1 s drive after each; (ii) one stage, constant f0PerSample arrays C1 then C3; (iii) fresh stage in
   another algorithm, setFundamentalHz, then setAlgorithm (re-key at start()); (iv) fresh stage at Amount 0 (bypassed:
   setFundamentalHz does not reach the branches), then setAmount(1) (re-key at leaveBypass); (v) fresh stage,
   setFundamentalHz, reset(). Post tilt (and pre tilt for Tube/Bite) compared C1 vs C3 per harmonic, bar 1.5 dB.
8. SC-028(c)/(d) fixture: kSawAnchor E1, 48 kHz, Amount 1 (unstated in the task). The saw is required for (d): on a
   sine the k = 1 pre tilt is unity at the only input harmonic (its pivot), so a pre-clip tilt cannot move THD there.
   (d) de-tilts every harmonic below fs/2 by |H_post(n f0)|^2 and applies the OQ-S floor rule (Sct::amountMoved
   restricted to THD and R_oe). Corroborating arm: seamPostToneNeutral_ (no de-tilt needed). Negative control:

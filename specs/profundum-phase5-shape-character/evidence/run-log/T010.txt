C-23 DESIGN GAP (task section): HOLLOW's base-rate input while BITE is on
- CHOICE: the exact first-order inverse shelf of BITE's emphasis tilt, at the base rate, on HOLLOW's tap
  (the form the T001 bench costed: one one-pole at fs). The second upsample was NOT used.
- Law: the tilt is H(z) = gH + (gL - gH)(1 - a)/(1 - a z^-1) (keytracked_tilt.h process(), one_pole.h
  y = (1 - a)x + a y[n-1]). Hence 1/H = (1 - a z^-1)/(b0 - gH a z^-1), b0 = gL(1 - a) + gH a; minimum phase
  (pole gH a / b0 < 1 for gL, gH > 0). a, gL, gH are recomputed with the tilt's own formulas (updateGains in
  double; OnePoleLP clamp at 0.495 fs and a = exp(-2 pi fc / fs) in float), so the inverse tracks the tilt
  coefficient for coefficient. Active only while BITE and HOLLOW both run (s in (0.5, 1)); reset on either's entry.
  Private nested struct ShapeMorph::InverseEmphasis (no namespace-scope name; no ODR exposure).

DEVIATION (surface): HOLLOW's decimated tap needs a second decimator
- The bench (T001 epoch 2) used BenchResidualPath::downsampleSplit(), returning the decimated linear path lb and the
  residual rb separately. The real OversampledResidualPath (T005, processors/oversampled_residual_path.h) has only
  downsample(lin, res) -> lb + rb; it is outside T010's file list, so it was not edited.
- Implemented: the path decimates lin = w_NL * l and res = w_NL * (y_NL - l), so its output is exactly
  nl = w_NL * lb + rb (what the bench formed from the split). HOLLOW's lb comes from a per-channel
  PolyphaseHalfbandOversampler `hollowDown` (downsampler only, same factor) fed the same tap l: same filter and
  input, so lb equals the path's linear decimation exactly. It runs only while HOLLOW is on (reset on entry).
- Cost vs the benched design: +1 halfband decimation per processed channel while HOLLOW runs (s in (0, 1)); none at
  SHAPE 0 or 1. The gated worst Shape cell in the epoch-2 lane was shape_0.00 (ROUND only, 0.782 % linked), which this
  change does not touch; shape_0.25 (0.773 %) and shape_0.75 (0.618 %) gain the extra decimation. SC-015 (T021 / T027)
  measures it on the real header. Cheaper alternative for the main loop: append a `downsampleSplit(lin, res, lb, rb)`
  to OversampledResidualPath (an append to a Phase 5 header owned by T005) and drop `hollowDown`.

Implementation (plan S5.4 Fracture, C-5 combined law, C-24)
- phi in [0, 2) in periods of f0, 0 at reset; each F-sample uses phi, then phi += f0/(F*fs) (so phi[0] = 0 literally).
- s = sin(pi*phi) from a DOUBLE rotor (cos, sin)(pi*phi), advanced by (cos, sin)(pi*dphi) and re-normalised every
  F-sample (1.5 - 0.5|r|^2). s_mid = sin(pi*(phi - dphi/2)) = rotation of the rotor by -dphi/2 (no transcendental).
  std::sin / std::cos run only in setFundamentalHz (the re-key), which stores the increment and re-seeds the rotor
  from the double phi: f0 moves the rate, never the phase. The bench prototyped the rotor in float; double was chosen
  because a float rotor's rounded step angle drifts the rotor against phi systematically (~6e-8 rad/step, i.e.
  ~1e-4 relative frequency error at E1 / 192 kHz) and the cost difference is a few scalar multiplies.
- sigma = fractureTanh(4 s) / tanh 4 and the bias term fractureTanh(g*beta*s_mid): Pade (7,6) clamped to [-4, 4],
  max |err| 1.50e-5 on the 10001-point grid (node re-check this session: 1.495e-5 at x = -4; T001 bench float
  1.499e-5). FastMath::fastTanh (core/fast_math.h:65, Pade (5,4), returns +-1 from |x| >= 3.5) misses the 1e-4 bar
  (error 1.8e-3 at 3.5), so it is not reused; core/fast_math.h is untouchable (FR-064), hence a private static.
- v = g*(u*((1 - a) + a*sigma)/P + beta*s), a = A, g = 0.5 + 1.5A, beta = 0.5A;
  y = (P/g)*(TanhADAA[drive 1](v) - tanh(g*beta*s_mid)); post tilt (k = 2, +-12 dB) at base rate (C-23).
- lin = (1 - a)*c_frac(A)*(u + u_prev)/2; c_frac[65] = h1 of tanh(g sin phi)/g over 256 midpoint points, prepare only.
- Observer: unchanged from T009 (updateObserver tracks flippedFrac_ with kFractureFlipEdges; r = 0.5 while flipped).

Decisions / deviations (surface them)
1. The phasor test verifies phi through the law rather than reading phi (DEFECT below). The equivalence is stronger
   than the task's increment bound: any phase jump or non-zero start fails the RMS bar by >= 100x (negative control).
2. SC-011 for Fracture averages over whole f0/2 periods (bcsDcDbfs(y, fs, f0/2)); the shared bcsDcSmoke averages over
   whole f0 periods, which for an odd count would leave the f0/2 subharmonic's partial-period mean in the "DC".
3. Risk for the gate (not a change): TanhADAA (primitives/tanh_adaa.h:224-270) evaluates ADAA1 in float, so
   (F1(v) - F1(v1))/dv loses ~ulp(F1)/dv when |dv| is just above its 1e-5 fallback. The Node model puts that noise
   at RMS ~4e-5 (pre-decimation), below the -80 dBFS bar, but the C++ smoke (ii) is the measurement. If (ii) fails,
   the fix needs a ruling (C-24 says "The ADAA stage stays TanhADAA"); a double-precision ADAA1 (as Bite / Rectify
   use via ClosedFormAdaa2) is the candidate.

DEFECT: dsp/tests/unit/systems/bass_character_stage_probe.h has no accessor for the Fracture phasor (phi / rotor), so
  T015's "phi starts at 0 / |phi[n] - phi[n-1]| <= C3/(F*fs) + 1e-6" cannot be read directly; tested through the law
  instead (decision 1). A static `double fracturePhase(const Stage&, int ch)` returning ch_[ch].frac.phase would allow
  the literal check.

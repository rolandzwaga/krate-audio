Implementation (plan S5.4, C-8, C-10, C-11, deviation 9; C-23 structure kept from T009)
- Bite: pre tilt (k=1, +-6 dB) at base rate (C-23); at F*fs v = g*u/P with g = 10^((-12 + 30A)/20); y = (P/c_bite(A)) *
  ClosedFormAdaa2<DiodeAdaaLaw>(v) in double; lin = u[n-1]; post tilt (k=2, +-6 dB) at base rate. c_bite[65] =
  diodeH1Coefficient(g(A_i)), filled in BiteBranch::prepare, interpolated linearly in A. configure recomputes g/P and
  P/c only on a changed Amount bit pattern.
- Bite naive (seamNaiveBaseRate_): y = (P/c_bite) * Asymmetric::diode(g*pre(x)/P) at the base rate, no path, no ADAA.
- Tube: pre tilt at base rate; at F*fs a branch-local PolyphaseHalfbandOversampler (factor 2) up -> TubeStage::process(buf,
  2) -> down; lin = u[n-2]; post tilt at base rate. Input gain -6 + 18A dB; output gain -20log10 c_tube(A) clamped +-24 dB.
  c_tube[65] = h1 coefficient of Asymmetric::tube(g*P*sin)/P over 256 midpoint phase points (same quadrature as
  diodeH1Coefficient), filled in TubeBranch::prepare. setSaturationAmount(1), setBias(0) at prepare (T009).

Decisions / deviations (surface them)
1. Tables live inside each channel's branch struct (one copy per channel, ~260 B each), not as stage-global members as
   plan S5.2 lists them. Reason: the branch structs are the units the probe drives (deviation 10) and the mono link copies
   ch 0 -> ch 1 wholesale; a pointer to a stage-owned table would dangle on a stage copy. Filled only in prepare.
2. Tube gain smoothing: TubeStage has its own 5 ms gain smoothers. After a branch reset (start(), leaving bypass, reset(),
   prepare()), the first configure sets the gains for the current Amount and calls TubeStage::reset() (snaps its smoothers;
   its DC blocker is already zero), so a starting Tube branch never glides from a stale Amount's gains. Outside that,
   gains follow the stage's 10 ms Amount smoother through TubeStage's 5 ms smoother.
3. P is HarmonicFold::kCalibrationPeak (the stage now includes processors/harmonic_fold.h, L2, as shape_morph.h does) and
   core/sigmoid.h for Asymmetric::tube / Asymmetric::diode.
4. The model values printed by the smoke INFO lines are plan S10.3 / S10.4: Bite worst A -83.3 dBFS, SC-007 6.27 dB (no
   octave figure in the plan; printed as 0); Tube worst A -85.3 dBFS, SC-007 4.89 dB / 0.40 oct.

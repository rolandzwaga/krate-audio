   [0.5 s, 1.0 s) whose S·f0/fs is nearest an even integer, so the end-setting reference is phase-aligned as the spec's
   method requires. Recorded per cell (INFO).

   >= 2·N from every reference detection with the largest |a| + |b - a| proxy (the ShapeMorph T013 pattern).

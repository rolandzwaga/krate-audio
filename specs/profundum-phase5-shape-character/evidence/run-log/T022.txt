- bass_character_stage.h: syncPhase(float coreCycles). Non-finite is ignored. It sets syncCycles_ = coreCycles mod 2
  and phaseSynced_ = true, then on both channels sets Crush theta = frac(coreCycles) (one phasor drives both hold
  engines) and Fracture phi = coreCycles mod 2, with the rotor re-seeded from phi. Running form: a single stage clock
  (syncCycles_, mod 2) advances by f0_/fs at the end of every sample once synced, whether bypassed or not.
  startBranch() then takes theta and phi from that clock instead of 0, so a switch or a bypass exit reads the
  running phase. Cost is one double add per sample, against keeping the inactive branches' phasors running. reset()
  clears the sync (phaseSynced_ false, clock 0) before it restarts the branches. No allocation.

DEVIATIONS / DECISIONS (surfaced)
1. VoiceEngineScript gains two fields beyond the task's list: tappedVoices (default kMaxVoices; per-sample voice
   taps cost 13 floats per sample per tapped voice, ~140 MB for 8 voices x 7 s at 48 kHz, so callers that need one
   voice set 1) and countAllocations (an AllocationScope around the render loop only, prepare outside; result in
   taps.allocations), for T011's SC-022 arm through the driver.
2. The per-voice tap set is VoiceEngineVoiceTapSet (the task's "VoiceTapSet"), to honour the prefix rule.
3. Endpoint events: index 0 / 1 selects endpoint A / B and the state endpointStates[index] (validated with
   isValidMorphState before the render).
4. Frame readers (S9.11): an 8-period frame is round(8 fs / f0) samples, not whole periods for a non-integer period
   (E1: 9319.7). A plain DFT on the rounded frame leaks ~1e-4 of h1 into P_{>=9}, i.e. ~60 dB above a -60 dB
   harmonic, so P_DC, P_1..P_8 are the least-squares projection onto {1, cos n w k, sin n w k}_{n<=8, below
   Nyquist} (exactly the DFT bins on a whole-period frame) and P_{>=9} is the residual's mean square (= P_total -
   P_DC - sum P_n by the projection theorem). Basis and Cholesky factor built once per (length, f0, fs).
5. L_K per frame = kWeightedLevelDb's value on the frame (fresh filter from sample 0), computed with one filter pass
   per channel; the FrameReaders case checks three frames against kWeightedLevelDb itself (1e-9).
6. Frame D_nl uses dNlDb's floor (BassMorphTest::floorPower of the twin frame's P_1); S9.11 names no floor.
7. S9.9 bound: 1.1 (G_max D_max + S_max P_max + dropSlope P_max), dropSlope = |A| max|d'| ln2 / 12
   (voiceEngineDropSlope); the glide term is Phase 4's own method (spectral_test.cpp:1079-1080: covered by D at the
   upper step's frequency), exposed as voiceEngineGlideStepKeyHz. W = [steal grid, fade end + round(fs / min f0)).
8. TwinDiffersOnlyInExcitation: forceLinearCore zeroes the HANDED excitation (profundum_voice.h:410-420), not
   state_, so the grid afterMotion states are expected bitwise equal; the case asserts that every differing leaf is
   excitation.mix (none expected), that the main state carries mix 1, and that every CoreExcitation record reads 1
   in the main render and +0 in the twin.
9. Summed core / Character / Anchor taps start at -0.0f (the IEEE additive identity): with one voice they are that
   voice's taps bit for bit. In PostSum (C-14) the summed Character tap is the voices' discarded per-voice Character
   output, not the global stage's (the engine exposes no tap for the latter).

DEVIATIONS (surface; do not silently revert)
  1. ProfundumMotion_Sources runs 4000 intervals, not 2000. At fs/32 = 1500 Hz, 2000 intervals = 1.333 s, but a
     0.5 Hz sine starting at phase 0 reaches -1 at 1.5 s (2250 intervals); over 2000 the minimum is
     sin(2*pi*0.5*1.333) = -0.866, so tasks.md's "min <= -0.99" could never pass. The bars are unchanged.
  2. One include beyond plan S2's list: primitives/envelope_utils.h (L1, downward) for RetriggerMode, which the
     header names directly (plan S2: "every symbol a header uses is included directly"). Plus std headers.
  3. Plan S3.2 lists a member m_; it would be write-only (outputValue() returns clamp(m), which equals m since
     |v|, |amount|, depth <= 1), so it is not kept (no unused-private-field warning).
  4. motion.cyclePhaseDeg's open upper bound: a value >= 360 is clamped to nextafter(360, 0) (the [0, 360) box).
  5. Supersets of the task's cases (same bars): clock independence also checked for Drift vs a standalone
     BrownianDrift; PolarityAndScale also checks each polarity map bitwise against standalone LFO / ADSREnvelope /
     BrownianDrift and a known first value (Cycle at 90 deg reads the peak); ConfigChangeOnly runs Env, Cycle and
     Drift (Cycle with cycleRetrigger on and cycleFadeInMs 200, noteRestart at intervals 0 and 400);
     TempoAndSeed also rejects +inf and has a positive control (60 BPM changes the synced Cycle).
  6. The test computes ((v * amount) * depth) and then multiplies a volatile-laundered copy by span, so that
     /fp:fast + -ffast-math reassociation on the test side cannot fold the constant chain into one multiply the
     header never performs; amount -0.75 and depth 0.5 make the first two products exact under any association.
  7. Order: in this session the header was written before the test file (both before any build). The tests have
     not been observed failing against the stub; the stub had no symbol, so they would not have compiled.

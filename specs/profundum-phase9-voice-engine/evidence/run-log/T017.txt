DECISIONS (surfaced; none changes a bar)
1. Evidence file names are per shard (monosum-<mode>.csv, anchor-chain-<note>.csv, *-smoke.csv) instead of the single
   evidence/monosum.csv and evidence/anchor-chain.csv the task names: the [long] shards run concurrently as separate
   processes (tasks.md deviation 9 lane), so one shared file would be overwritten or interleaved. Phase 8 precedent:
   evidence/sc016-monosum-E1-smoke.csv. follow-tracking.csv keeps its name (one [long] case) plus a -smoke file.
2. SC-015 SPREAD / WIDE cells run at spread 1 on both bases (A_s's own spread is 0, which would make the image mode
   a no-op); SOLID cells start in WIDE at spread 1 so the switch carries real L != R history into the re-sync.
3. SC-015 4-voice cells: root + {0, 5, 7, 10} st (the P-2 filler intervals, kP2FillerOffsetsSt), all note-ons at 0.
4. SC-015 gate taps: field (the safety-stage output, Phase 7 G8-1) and output (the full engine, the spec's SC-015
   wording). Phase 7's G10-2 rule is adopted (a cell whose lowest f0 >= f_c has no harmonic in the sub band ->
   recorded; with f_c = 120 Hz this makes the C3 cells sub-band records, their SC-016 and SOLID gates still run) and
   its validity rule (band < -60 dBFS not read). Phase 7's G8-1 anti-phase exemption is NOT applied: H-19 says
   "Gate through SC-015". If a B / Fold cell goes red on rho, that is the H-19 finding, to be surfaced, not exempted.
5. SC-017 "excitation 1" = mix, drive and asymmetry all 1 (the SC-021 setting's wording); R sets mix 0 only.
   E_sub for (b) is read on the Sum tap (the voice's summed fundamental, pre-dynamics), the same Sigma as (c).
6. SC-017 premise failures are CHECKs, not REQUIREs (plan S9.10 says REQUIRE): a REQUIRE would abort the shard and
   lose every later cell's CSV row; the cell still fails, and (c) is not evaluated on a cell whose premises fail.
   The same CHECK-not-REQUIRE choice holds for every per-cell gate in this TU (the CSV holds every cell).
7. [long] split (deviation 5): SC-015 sharded per image mode, SC-017 per note, SC-018 one [long] case; each with a
   smoke. Estimated, not measured (this task does not run): SC-015 8 renders x ~4.8 s audio, 1-4 voices; SC-017 60
   renders x 1.25 s per note; SC-018 ~140 s audio with a per-sample Anchor plus 2-3 anchorShsF0 frames per case. The
   build agent records each wall clock; a shard under 15 s may drop [long] at that time.
8. SC-018 sweep is a staircase (one Amount per 32-sample interval) because BassMorphEngine's ramp tops out at 2000 ms
   (bass_morph_engine.h:68); the event is still the single interval at which the ratio changes.

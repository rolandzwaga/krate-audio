  - Includes exactly plan S2's list: core/db_utils.h (detail::isFinite, db_utils.h:118), core/modulation_curves.h (applyModCurve,
    modulation_curves.h:37-55), core/modulation_types.h (ModCurve, modulation_types.h:79-84), primitives/envelope_utils.h
    (kMinEnvelopeTimeMs/kMaxEnvelopeTimeMs, envelope_utils.h:50-51), systems/morph_state.h; plus std headers.
  - Field ranges -12/12 dB (TransientShaper::kMinGainDb/kMaxGainDb, transient_shaper.h:78-79) and Fold 100 (harmonic_fold.h:166-169)
    are private literals, because S2's include list has neither header and rule 2 forbids transitive reliance.
  - contributions() ASSIGNS each row's value (one row per target, static_asserted) instead of summing onto +0: summing a -0
    (negative-amount row at the neutral) onto +0 yields +0 and would break the bitwise ContributionArithmetic check.
  - compressionContribution() returns contributions()[CompressionAmount]. An in-class constexpr row-index lookup was avoided:
    a static constexpr member initialised by a member constexpr function is ill-formed before the class is complete.
  - FR-050 invariants are public static constexpr predicates (documentedOwner, everyTargetClaimedOnce, noSteppedCurve,
    ownersDocumented, signsDocumented), static_assert'ed after the class, so no new namespace-scope name is introduced
    beyond the rule-2 list.
  - apply() skips a +-0 contribution (bit test) and guards x + c / t * exp2(c) with detail::isFinite before std::clamp (rule 3).
  - HARVEST markers: "// HARVEST-BEGIN macro-rows" / "// HARVEST-END macro-rows" wrap the kRows definition (deviation 12).

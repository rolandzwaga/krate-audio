DECISIONS
- Includes are exactly plan S2's list (+ <algorithm> <array> <bit> <cmath> <cstddef> <cstdint> <initializer_list>
  <span>). Three symbols reach the header transitively because S2's list has no row for them: kMaxPartials
  (processors/harmonic_types.h, via profundum_core.h / bass_stereo_field.h), RetriggerMode (primitives/envelope_utils.h,
  via adsr_envelope.h), DropCurve (core/drop_curve.h, via drop_envelope.h). Recorded, not added (S2's list is
  "exact"); adding them is a three-line change if T026 rules otherwise.
- MassLaw / BassMorphEngine kControlInterval static_asserts (S5.1 comment) are left to the engine (T008): neither
  header is in S2's list for profundum_voice.h. The voice asserts ProfundumCore, AnchorOscillator, BassStereoField.
- prepare: S5.3 step 1 (pre-prepare snap setters), step 2 (prepares; capHz_ from the clamped rate), then
  reset(initial), which re-issues steps 1 and 3 before resetting every component, so post-reset == post-prepare. The
  lock bypass is set from initial.anchor.mode at reset too, so the first interval's pitch stage (step 0, which
  precedes step 7's bypass) already runs bypassed in FOLLOW.
- Every S5.4 step emits exactly one ProfundumCallRecord per interval, in ProfundumCall order (FoldAmount, FoldF0,
  Shape as the enum orders them); issued only on a bitwise change of the handed argument, or on the first interval
  after prepare / reset (handedValid_). The pan vector is compared bitwise in the voice as well (the core's own change
  test does not make the call change-only). SyncPhase / NoteOnCore / NoteOnAnchor are logged only when issued.
- Transition timing: the dip switch is a countdown (untilSwitch_ = samplesUntilSwitch(), decremented per rendered
  sample), not an absolute position, so it is independent of the record clock. render splits a chunk at the switch,
  applies the pending transition there, reruns the pitch stage from the switch, and re-runs FR-012's pan step after
  fieldState_.reset() when the core takes its Reset branch. A switch landing on sample 0 is applied at
  beginInterval step 0.
- Meter (S9.6): rotor step recomputed at every 16-sample core pitch update (coreGridCount_ % 16 == 0) and at the core
  note-on sample; f = clamp(f_core, kMinF0Hz, capHz_) (a non-finite f_core keeps the previous f, never reaches
  std::clamp); thresholds compared as amplitude ratios 10^(-22/20) / 10^(-18/20) (no log of 0); theta() never
  returns 1.0f by float rounding.
- a1 (C-6): cached shape keyed on the six recipe fields, mask keyed on fAnchor[0] bitwise, applyMask when either
  changed, spans of exactly 64; evaluateMask gets the fs handed to prepare (unclamped), as unbiasedH1Amplitude does.
- anchorPhase tap: per sample under the anchorPhaseTap seam; otherwise the phase after the chunk, replicated.
- Test sum buffers are cleared to -0.0f per chunk (the IEEE additive identity), so the sum holds the voice's
  contribution bit for bit, -0 contributions included.

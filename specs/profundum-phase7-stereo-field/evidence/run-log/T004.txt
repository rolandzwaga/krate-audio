## Decisions
1. Upper knee tested in Hz (f >= 4 f_c,s; the product by 4 is exact), in addition to x >= 1. Reason: the
   tests demand widthCurve(480) == 1.0f exactly at f_c 120 and c == 1 for every f >= 4 f_c, and
   fl(log2(480)) - uLow_ times invSpan_ can round to just below 1. Same law (C-5), exact at the knee.
2. Zero is +0 (rule 4): target = mag > 0 ? (k even ? -mag : mag) : +0, so SOLID / Spread 0 / c = 0 never
   emit -0 (the C-15 gate uses bit_cast, so -0 would fail).
3. Slew: `if (!(|d| <= delta)) v = prev + copysign(delta, d)`; else v = target (lands exactly). Entries 0 and
   k >= N are written +0 without slew (FR-010 / FR-013). numPartials clamps to [0, 96] (negative -> 0).
4. Handoff count compares all 96 entries by bit pattern against state.previous (plan S11), then stores
   previous, primed = true, lastCrossoverHz = fcS_. The method is const: no field member is written.
5. Printed readings (landing query, Cycle handoffs, positive-control step, curve-step W change, C-17 W paths
   and excursions) go to std::cout with a "[T004 ...]" prefix (Phase 6 precedent:
   mass_dynamics_aliasing_test.cpp:165, 243).
6. Small non-vacuity additions, in scope: MotionInwardLaw requires the smallest |p| / P over the wide
   partials < 0.9 (MOTION actually moved the vector); PanVectorShape also checks numPartials -3 and an Inf f0.

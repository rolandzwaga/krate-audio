## Decisions
- Pass criterion per mono cell = StereoFieldTest::monoSumCellPasses (the helper the task names), which gates
  |Q_sub| <= 1 dB and every valid octave Q >= -3.11 dB at core / stageOut / out and rho_sub >= 0.99 at core and
  stageOut. The task's parenthesis "(sub-band rows and rho)" is read as describing that helper; it is the
  stricter reading (octave rows included). The worst octave Q is printed beside it so the aggregator / main
  loop can see whether an octave row, not the sub band, decided a FAIL.
- "worst Q" in the side-floor line = the minimum Q_sub over the gated taps (Q <= 0 dB always, so the largest
  |Q_sub|, the SC-001(a) quantity g_floor drives); the worst octave Q is in BSF_HARVEST_FLOOR_ROW.
- Step 1 curve: the task lists no curve axis, so the cells run at Controls{}.curve (0.5). Gravity 0, depth 0,
  g_floor 0.5 via sideFloorOverride, K via wideScaleOverride, dirty arm without the Anchor (rule 10).
- Step 1 SC-007: measured on every Spread 1 cell at E0, E1, E2 (all three crossovers), characterL and characterR,
  wideAliasedDbfs <= -80 dBFS. Those cells render max(descriptorSeconds, 1 s + aliasFftLength(fs, f)/fs)
  because aliasFftLength at E0 is 2^18 (2^19 for Fracture, f = f0/2), more than descriptorSeconds holds after
  the settle (wideAliasedDbfs REQUIREs it). The longer render does not change the mono-sum reading (one window
  of <= 2^18 samples from the settle).
- Step 1 SC-010 lever: dirty Tube arm, no Anchor, Controls{} with mode SPREAD vs WIDE, g_floor 0.5, E1 and C3,
  staticLeverMove at f_c 120 >= 3 dB or >= 0.1 at both notes. The SPREAD reference renders once per note
  (wideOffsets is {+0, +0} outside WIDE, bass_stereo_field.h:400-406).
- Candidate PASS (step 1) = every mono cell passes AND worst alias <= -80 AND the lever passes at E1 and C3.
  The chosen K is the first PASS in the order {1, 0.75, 0.5}; STOP AND SURFACE only when none passes (plan S9.1
  step 3 "if step 1 fails at 0.5").
- Step 2: the render runs at the committed kSideFloorGain / kWideOffsetScale (no overrides; T015 pastes K_wide
  before step 2), then StereoFieldTest::restage(taps, cfg, g) per candidate and evaluateMonoSumCell on the
  restaged taps (stageOut / out replaced, core original). Grid per shard = 3 modes x 4 notes x Spread {0, 0.5, 1}
  x crossover {60, 120, 250} x curve {0, 1} = 216 cells at Gravity 0, depth 0 (deviation 7); CHECKed.
- Lever (step 2): showcase = SPREAD, kSawAnchor clean core, Controls{} at Gravity 0 and 1, E1 and C3; both renders
  restaged at each g (the Gravity 1 render is g-independent, restaged anyway for symmetry).
- Nothing REQUIREs a candidate to pass (the harvest measures; the aggregator decides). The only asserts are the
  cell-count CHECKs and the arm-name REQUIRE.

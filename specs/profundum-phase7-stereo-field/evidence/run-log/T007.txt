## Decisions
- bypassField: plan S10 says "stage not run, vector not handed" and the C-12 self-test needs exactly that (a handed
  Spread 0.5 vector would change coreL/R). tasks.md T011 (BassStereoField_NoZipper) uses bypassField "so only the
  vector is handed". Both are served by a second flag, `bypassHandsVector` (default false): T011 must set
  bypassField = true AND bypassHandsVector = true. The law is advanced, queried and recorded either way; the
  WIDE offsets are always handed (S10 names only the vector).
- Note-on: S10 step 3's "retrigger from perInterval" has no channel in perInterval's signature
  (void(sample, BassStereoField&)); the only note-on is chain.noteOnSample. perInterval runs on the main field only
  (not on the generatorGravity field) and must be a pure function of (sample, field), because restage replays it.
- vectorPerInterval records the vector handed (after forceSubCentre; from the generator field when
  generatorGravity is set). offsetsPerInterval records the offsets handed ({+0, +0} without a character stage).
- f0At: the per-sample f0 (rounded to float once) feeds the core, the Anchor, ShapeMorph and the character stage
  through their f0PerSample arguments; HarmonicFold (setFundamentalHz), the MassDynamics detector key and the
  Anchor's a1 (unbiasedH1Amplitude) take f0At at each grid point; the note-on uses f0At(noteOnSample). Without
  f0At none of those extra calls happen (C-12 bit-exactness).
- core.setExcitation is called only when cfg.excitation differs bitwise from ProfundumCore::kDefaultExcitation.
- The probe overrides are applied before prepare(), so prepare's reset() snaps the side-gain smoother to the
  instance floor; restage's field takes floorGain the same way, so a restage at g equals a full render with
  sideFloorOverride = g (deviation 7), not a 10 ms glide from the old floor.
- bandReading: window = the first largestPow2AtMost(n) (<= 2^18) samples from the pointers passed; meanEnergy is
  taper-compensated ((ll + rr) / 2 / sum w^2), so valid = mean-square >= 1e-10 of the untapered band. A silent band
  reads Q = 0, rho = 0, side-to-mid at the floor, valid = false. rho = 0 when one channel is silent.
- MonoSumCell "worst over windows": among valid windows, min Q (Q <= 0 dB always, so also max |Q|), min rho, max
  side-to-mid, min mean energy; a band valid in no window stays invalid. monoSumCellPasses skips invalid readings
  (e.g. the [0, 60) sub band at E2 / C3 holds no harmonic), as SC-001(b) skips invalid octaves.
- evaluateMonoSumCell reads f_c and MOTION depth from the controls of sample 0 (fieldAt(0) or `field`).
- renderPanReference: a_n carries the bank's centre gain (fitted on one channel of a Spread 0 render), so the
  channel gains are sqrt(2) cos / sin(pi/4 + p pi/4); cyc integrates f0At(j) / fs from sample 0 (the core's Reset
  phase 0 at note-on). fitHarmonics (new, small) rotates each fitted phase back to sample 0 for a static f0.
- No build or run (executor rule); both files re-read for compile hazards (qualified TestUtils, designated
  initialisers in declaration order, no narrowing, explicit casts).

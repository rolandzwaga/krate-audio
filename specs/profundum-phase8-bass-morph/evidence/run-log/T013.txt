Decisions
1. Frozen render length = kSettleSeconds + aliasFftLength(fs, f0/2)/fs + 0.05 s (rectifier_test.cpp:144 precedent),
   for every point of a note. The default descriptorSeconds (1 s + 262144/fs) is shorter than the Fracture frame
   at E0 (aliasFftLength(96000, 10.3 Hz) = 1 048 576 samples) and wideAliasedDbfs REQUIREs size >= L + settle
   (bass_stereo_field_test_helpers.h:1120-1125). Using the f0/2 frame length for Tube points too only lengthens
   their settle; the read is always the last L(selected algorithm) samples.
2. (b) ramp: the Position 1 event at 0.25 s (floored to the 32-sample grid), rampMs 1000, render 1.5 s, so the
   note has sounded before the ramp starts (maxNonlinearPair's switch is at its first interval with p > 0, which
   would otherwise be the note-on interval). Recorded only.
3. (b) per-bin power: direct DFT at the window's own bins m/T, normalised so the one-sided sum is the windowed
   mean square, reported dB re 0.5 (0 dBFS sine), the convention of HarmonicFoldTest::aliasedPower. DC is
   excluded (within 2/T of 0*f0). The excluded fraction is printed beside each value.
4. Supplementary (b) columns excluding every k*f0/2 (Fracture's output period is 2/f0, the spacing
   wideAliasedDbfs uses for it). Recorded only.
5. FTZ / DAZ: enableFTZDAZ() at the top of each case (the bass_morph_helpers_test.cpp / bass_morph_probe_test.cpp
   precedent of T007 / T008); not restored on exit, as in those TUs (the test binary enables it globally anyway).
6. The (a) bar is CHECKed (every point is evaluated and printed even after a red); the selection / arm preconditions

FOR THE MAIN LOOP (spec-level observation, not a code defect, not gated)
- The SC-017(b) measure as worded is degenerate for every Phase 8 note: the window is T = 1/f0 + 10 ms, so the
  exclusion half-width 2/T Hz exceeds f0/4 whenever 4 >= f0*T = 1 + 0.01*f0, i.e. for every f0 <= 300 Hz. The
  exclusion bands around consecutive k*f0 then overlap and every in-band bin is excluded: E0 (T = 58.5 ms, +/-34 Hz
  vs 20.6 Hz spacing), E1 (T = 34.3 ms, +/-58 Hz vs 41.2 Hz), E2 (T = 22.1 ms, +/-90 Hz vs 82.4 Hz). The record will
  read the numeric floor (safeDb10 of 0, about -3000 dB) with excluded_fraction 1. The test writes it as specified
  and prints the excluded fraction so the reading is self-explaining. A meaningful (b) record needs a ruling
  (e.g. a longer window or a narrower exclusion); (a) - the gate - is unaffected. Spec SC-017 states (b) is covered
  by composition, so no bar is at stake.

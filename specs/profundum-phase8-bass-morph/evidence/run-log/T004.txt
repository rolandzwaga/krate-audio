Decisions (each a deviation from a literal reading, surfaced for the main loop; none relaxes a bar):
  D1 Default constructor. Plan S4.2 / S4.6 only refresh the log cache in setEndpoint, so an endpoint that is never
     set (MorphState{} default) would interpolate its Logarithmic rows from a zero cache (exp2(0) = 1: wrong
     values for e.g. dropTimeMs 100 ms). The constructor fills both caches from the defaults. No allocation; the
     engine stays copyable and nothrow-movable (BassMorph_InterfaceStatics' static_asserts unaffected). T005's
     restoreRuntime does not touch endpoints, so it needs nothing more.
  D2 Equal-power regrouping. FR-033 / plan S4.6 spell the radicand (1 - t) m_A^2 + t m_B^2. The resolver evaluates
     the algebraically identical m_A^2 + t (m_B^2 - m_A^2) in double: m_A^2 and m_B^2 are exact in double (48-bit
     products), the difference is t-independent, and t * d and the sum are correctly rounded and monotone in t,
     so FR-037 holds by argument for this law (the two-term form adds a decreasing and an increasing rounded term,
     which plan S4.6's monotonicity argument does not actually cover). The SC-019(b) closed form in the test stays
     the spec's sqrt(0.75 x_A^2 + 0.25 x_B^2); the two forms agree within 2 ulp by C-4's error analysis.
  D3 Test 2 "the other four groups' selections ... stay A's throughout": unsatisfiable as written, because rule 1

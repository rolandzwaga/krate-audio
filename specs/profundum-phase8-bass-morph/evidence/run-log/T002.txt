  - kLeafOffsets is built by a constexpr immediately-invoked lambda (the variable is constexpr, so it is evaluated at
    compile time). Plan wording "consteval-built"; a consteval lambda was avoided only for MSVC robustness. Not a
    behaviour change.
  - isValidMorphState's open-box test is written `v < hi || (!hiOpen && v == hi)` (no constant ternary condition,
    MSVC /W4 C4127 hygiene); generic-lambda parameters used only in some if-constexpr branches carry

  - randomValidState (plan S5.1, R-8): one raw word per row for the value, then for F32 one word for the 5 % edge

    is row-independent); then one word per governing amount (order characterAmount, field.spread, field.motionDepth,
    motion.amount, anchor.level). Log rows: exp2 of a uniform in [log2(lo + o), log2(hi + o)] minus o, in double,
    clamped into [lo, hi]. Added inline helper BassMorphTest::unitFromWord(w) = (w >> 8) * 2^-24 (shared by the
    generator and the TU's field-block draw). It is the only helper beyond the task's list.
  - randomValidPair: one draw per leaf in table order; B's leaf copied from A when u < pEqual.
  - ulpOf and the TU's nextafter directions use FLT_MAX / lowest instead of +-infinity (no infinity literal under

9.12 HarmonicFold path dependence above kSoftEnd (SC-006(b) record, ruling B10-3, 2026-10-19)
  - A -> B -> A returns the controls bitwise (SC-006(a)) but the render 0.126 / 0.130 dB off on one harmonic (h16 /
    h11) when A's Fold is 86.6 / 98.5, unchanged from 1 s to 8 s after landing; 0.003 / 0.0004 dB with A's Fold at
    20; the Anchor mode (Follow vs Lock) changes nothing (evidence/run-log/close/sc006-settle-probe.log).
  - Cause: HarmonicFold's windowed-peak detector releases only when the raw peak falls kDetectorReleaseHysteresis
    (0.5 %) below its envelope (harmonic_fold.h:99, Phase 2 D-4), so above the soft regime it latches a
    path-dependent envelope. By Phase 2 design, not a Phase 8 defect; SC-006(b) gates pairs with A's Fold <= 30 and
    records the rest (run-log/close/long/BassMorph_IdempotentRender.final.log, "SC006 recorded(b)" lines).
  - Phase 9's determinism harness and any A/B-compare feature inherit this: two paths to the same Fold >= 30 state
    can differ by ~0.13 dB on upper harmonics.
